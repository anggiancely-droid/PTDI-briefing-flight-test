# Aviation Weather Briefing — PTDI × BMKG × ITB (Final)
Platform briefing cuaca penerbangan interaktif berbasis web dengan integrasi data live BMKG dan ekspor laporan PDF otomatis.

## Cara Menjalankan
- **Mode Langsung (Statis)**: Buka file `index.html` di browser.
- **Mode Lengkap (Proxy Live BMKG + Canvas PDF)**:
  ```bash
  npm install
  npm start
  ```
  Lalu buka `http://localhost:3000` di browser.
